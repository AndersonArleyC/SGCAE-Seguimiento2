SGCAE

Sistema de Gestión y Control de Acceso de Empleados

Backend REST · .NET 10

Esta página documenta la API; no es una interfaz de administración.

Estado de la aplicación · Conexión SQL Server

  • /api/empleados — POST registrar / GET consultar con pagina, tamano y activo.
  • /api/empleados/{id} — GET detalle / PUT actualizar.
  • /api/empleados/{id}/desactivar — PATCH desactivar.
  • /api/empleados/{id}/credenciales — GET credenciales.
  • /api/credenciales — POST asignar. GET /{id}, PATCH /{id}/bloquear o /{id}/revocar.
  • /api/puntos-acceso — POST registrar / GET listar. PATCH /{id}/habilitacion.
  • /api/movimientos — POST registrar / GET historial con empleadoId, desde, hasta, puntoAccesoId, resultado, pagina y tamano.

Para ejemplos completos, consulte SGCAE.http en la carpeta del proyecto.

Importante

Versión académica local, sin autenticación. Use únicamente datos ficticios. No exponga esta API en Internet ni la utilice para controlar accesos físicos reales.
